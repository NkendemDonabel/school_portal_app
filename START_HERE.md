## 🎮 How to Use Each Module

### Adding a Student
1. Tap "Student Management"
2. Tap the "+" button
3. Enter name, email, grade
4. Tap "Add"
5. ✓ Done!

### Publishing an Announcement
1. Tap "Announcement Management"
2. Tap the "+" button
3. Enter title and content
4. Select target audience
5. Leave "Save as Draft" unchecked
6. Tap "Create"
7. ✓ Announcement published!

### Editing a Teacher
1. Tap "Teachers Management"
2. Tap the menu (⋮) on a teacher
3. Select "Edit"
4. Update information
5. Tap "Update"
6. ✓ Done!

### Deleting a Student
1. Tap "Student Management"
2. Tap the menu (⋮) on a student
3. Select "Delete"
4. Confirm deletion
5. ✓ Removed!
